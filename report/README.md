# BLG 475E Final Report (Phase 1 + Phase 2)

This directory holds the combined Phase 1 + Phase 2 report for the
ITU BLG 475E Software Quality and Testing course project.

## Files

- `report.tex` — IEEEtran journal-style combined report covering both
  phases. Sections I–VI are Phase 1; Section VII is Phase 2; Section
  VIII is the joint conclusion.
- `references.bib` — BibTeX entries for the five surveyed papers (the
  same set used in Phase 1; no Phase 2 additions).
- `figures/phase2_comparison.png` — per-variant headline metrics
  chart, generated by `python bookscan/make_comparison.py` from the
  repo root.
- `figures/phase2_prompt_effect.png` — per-LLM unmodified-vs-edited
  delta chart, same generator.

## How to compile

### Local LaTeX (TeX Live / MiKTeX)

From this directory:

```
pdflatex report.tex
bibtex   report
pdflatex report.tex
pdflatex report.tex
```

### Overleaf

1. Upload `report.tex` + `references.bib` + the `figures/` directory.
2. Set the compiler to **pdfLaTeX** and the bibliography backend to
   **BibTeX**, then click **Recompile**.

The IEEEtran class is included in standard TeX Live and Overleaf
distributions; no extra installation is required.

## How to regenerate the Phase 2 figures

The two PNGs in `figures/` are produced deterministically from the
Phase 2 JSON artefacts:

```
python ../bookscan/make_comparison.py
```

(`matplotlib` ≥ 3.0 required; no other dependencies.) The script also
re-emits `../bookscan/reports/comparison.md` and
`../bookscan/reports/comparison_data.json`.

## What to submit to Ninova

The Ninova upload is the **PDF only**. The code, prompts, logs, and
analyses live in the GitHub repository named in the Acknowledgments;
the report cites the repository URL so the evaluator can navigate
the artefacts directly. Do not zip the source tree into the Ninova
upload.
