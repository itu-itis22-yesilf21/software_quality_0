# BookScan — Phase 2 Workspace

This directory holds every artefact produced during Phase 2 (Integration
Testing) of the BLG 475E project. Phase 1 artefacts continue to live at the
repository root (`generated_java/`, `gemini_process/`, `coverage_reports/`,
etc.) and are not touched here.

## LLM identities (carried over from Phase 1)

| Label | Model | Phase 1 location |
|---|---|---|
| **LLM A** | GPT-5.5 | `generated_java/Java_X/` |
| **LLM B** | Gemini 3.1 Pro | `gemini_process/generated_code/Java_X/` |

Source: project `README.md` on `main` ("GPT-5.5 and Gemini 3.1 Pro were used
during the solution generation, test generation, and analysis workflow.")

## Prompt variants

Phase 2 requires comparing the code generated by an **unmodified+combined**
prompt against the code generated by an **edited+combined** prompt. The
matrix is therefore four `BookScan` variants:

|              | Unmodified prompt          | Edited prompt           |
|--------------|----------------------------|-------------------------|
| **LLM A**    | `llm_a/unmodified/`        | `llm_a/edited/`         |
| **LLM B**    | `llm_b/unmodified/`        | `llm_b/edited/`         |

Each variant directory will eventually contain:

- `BookScan.java` — the agent-generated class
- `BookScanIntegrationTest.java` — agent-generated integration tests
- `BookScanBlackBoxTest.java` — ECP/BVA mutation tests (added when needed)

## Subdirectories

- `llm_a/` and `llm_b/` — generated classes and tests per variant
- `logs/` — full prompt/response logs for every LLM interaction
- `coverage_reports/` — JaCoCo branch/instruction coverage per variant
- `reports/` — raw test run output, smell findings, failure analyses

All commits affecting this directory follow the `Phase 2 / Step N: …`
convention defined in `phase2.md`.
